# Canvas Mindflow

> 划线追问的 AI 学习对话插件 · An Obsidian plugin for highlight-to-ask AI study chats

读 AI 的回答时，哪里看不懂就**划线追问**：追问以卡片堆叠在右侧，可以无限展开成一棵问答树；还可以对划线写**想法笔记**、把问答放进**多级收藏夹**、一键生成 **Canvas 总览图**。支持 Windows / macOS / Linux 桌面端，以及安卓、iPhone / iPad 上的 Obsidian。

*English: Ask an AI, highlight anything you don't understand to branch a follow-up, and keep exploring as a tree. Includes highlight notes, nested favorites, image/PDF attachments, preset follow-up questions and Canvas overviews. Works with any OpenAI-compatible API (DeepSeek, OpenAI, Kimi, Qwen, GLM, SiliconFlow, OpenRouter, Ollama…). UI is in Chinese.*

## 功能一览

- **划线追问**：选中回答里的一段 → 输入问题或点预设问题 → 右侧生成追问卡片，原文黄色高亮，点击跳转；公式和符号会完整保留。
- **问答树**：窗口内继续提问（1、2…）和划线分支（1.1、1.1.1…）都在右侧树里，点哪跳哪。
- **想法笔记**：对划线的句子记下当时的想法，按文件夹分类，点笔记跳回原文。
- **收藏夹**：多级收藏夹，收藏单轮问答或整个对话，可整夹导出为 Canvas。
- **图片 / 文件**：粘贴截图、拖入文件或点 📎 添加；PDF 和文本文件自动提取文字，图片按多模态格式发送。
- **回答编辑**：右键编辑 AI 回答、加入自己的理解，之后的追问以修改后的内容为上下文。
- **Canvas 卡片对话**：也可以直接在 `.canvas` 卡片里提问，回答写在卡片里，可折叠、可划词分支。
- **Markdown 原生渲染**：表格、代码、LaTeX 公式（含 `\[ \]` / `\( \)` 写法）。
- **移动端适配**：窄屏自动切换单栏 + 抽屉，长按选字后底部出现「追问 | 笔记 | 复制」。

## 安装

### 方式一：从 Release 手动安装

1. 到 [Releases](https://github.com/Unclesam-13/canvas-mindflow/releases) 下载最新的 `canvas-mindflow-x.y.z.zip`。
2. 解压得到 `canvas-mindflow` 文件夹，放到 `你的库/.obsidian/plugins/` 下。
3. Obsidian → 设置 → 第三方插件 → 关闭安全模式 → 刷新 → 启用 **Canvas Mindflow**。

### 方式二：用 BRAT 安装（自动更新）

安装 [BRAT](https://github.com/TfTHacker/obsidian42-brat) 插件 → `Add Beta plugin` → 填入 `Unclesam-13/canvas-mindflow`。

### 方式三：iPhone / iPad

插件本身不分平台，iOS 上的 Obsidian 直接用同一个插件（`manifest.json` 里 `isDesktopOnly: false`）。iOS 的「文件」App 默认看不到 `.obsidian` 隐藏文件夹，推荐下面两种装法：

- **BRAT（推荐）**：在 iOS 的 Obsidian 里：设置 → 第三方插件 → 关闭安全模式 → 浏览 → 搜索安装 **BRAT** 并启用 → BRAT 设置里 `Add Beta plugin` → 填 `Unclesam-13/canvas-mindflow` → 回到第三方插件列表启用 **Canvas Mindflow**。以后有新版本 BRAT 会自动更新。
- **同步过去**：如果库是用 iCloud、Obsidian Sync 或 Remotely Save 等同步的，先在电脑上装好插件，确认同步设置里包含「插件」/ `.obsidian` 文件夹，iOS 端同步后在第三方插件里启用即可。

iOS 上的用法和安卓一样：单栏 + 左右抽屉，长按选字后底部出现「追问 | 笔记 | 复制」，📎 可以从相册或「文件」里添加图片和 PDF。

### 配置

设置 → Canvas Mindflow → 选择服务商（或自定义 OpenAI 兼容地址）→ 填写 API Key → 「获取列表」选模型 →「测试」。

## 使用说明


## 对话视图（划线追问）

打开方式：左侧功能区的「💬 Mindflow 对话」图标，或命令面板「Canvas Mindflow: 打开对话视图」。

1. **开始对话**：在底部输入第一个问题，Enter 发送，AI 的回答会实时渲染成 Markdown（表格、公式、代码都支持）。
2. **划线追问**：在回答里选中看不懂的一段 → 弹出「追问」小窗 → 输入问题点「发送追问」（留空 = 详细解释这段）。拖选时公式和符号会和文字一起显示选中色，弹出追问框后选区仍保持高亮。
3. **右侧出现追问卡片**：追问的回答在右侧卡片里生成；主窗口里被划线的文字变成黄色高亮，点击高亮会跳到对应卡片并展开。
4. **切换主窗口**：点击右侧某张卡片的标题，这个追问就变成主窗口，用法和主窗口完全一样（可以继续提问、继续划线追问）。多个追问以卡片形式堆叠，用 ⌄ 只展开预览。
5. **问答树**：右侧栏上方「问答树」标签显示整段探索的层级和你当前所在的位置（例如 1. 怎么开始炒股 → 1.1 什么是杠杆 → 1.1.1 爆仓是怎么发生的），点击任意一项即可跳转；在同一窗口里用输入框继续问的问题也会以 ↳ 列在对应窗口下面（点击会跳到那条消息），划线追问的分支下方会显示当时划的原文；「追问」标签回到当前窗口的追问卡片。
6. **返回上一层**：主窗口标题左边的 ‹ 按钮；标题上方显示来路。
7. **生成总览图**：左侧栏「生成总览图」或右侧问答树底部的按钮，会在 `Mindflow/总览图/` 生成一张 Canvas，把所有问题连成树状网络；每张卡片有摘要预览，点标题或「打开对话 →」跳回对应窗口。
8. **左侧栏**：「历史 / 收藏夹 / 笔记」三个按钮点哪个就切到哪个。「历史」列出所有对话，被收藏过的对话左下角有黄色小星星；右键可加入收藏夹、生成总览图或删除。
9. **侧栏**：标题栏最左、最右的两个按钮分别展开 / 收起左侧栏和右侧栏；拖动侧栏与主窗口之间的分隔线可以调整宽度，双击分隔线恢复默认宽度。宽度和开关状态会记住。
10. **编辑回答**：在回答上点右键 →「编辑回答」（或操作栏里的 ✏️），可以直接修改 Markdown 内容、加入自己的理解，保存后标注「已编辑」；之后的追问会以修改后的内容为上下文。右键菜单里还能「恢复 AI 原始回答」。右键菜单同时提供 复制、重新回答、保存为笔记、删除；选中文字后右键可以「追问选中内容」。
10a. **回答操作栏**：每条回答下方有 复制（Markdown）、重新回答、保存为笔记、继续追问、删除这一轮，并显示时间、模型和字数；你的提问下方有 复制、编辑后重新发送。
11. **划线追问的预设问题**：在设置 →「划线追问的预设问题」里添加常用问题（可增删、调整顺序）。划线后右键菜单里会列出「追问：…」，追问小窗里也会以按钮显示，一点就发，不用每次打字；手机上点「追问」后，输入框上方同样会出现这些问题。
11a. **图片和文件**：输入框左边的 📎 可以添加图片或文件，也可以直接粘贴截图、把文件拖进对话窗口。
    - 图片按多模态格式发给 AI，需要模型支持看图（DeepSeek 目前不支持）。可以在设置 →「图片识别模型」里单独填一个支持图片的模型（如 gpt-4o、qwen-vl-max、glm-4v），带图片的提问会自动改用它。
    - 文件支持 PDF（自动提取文字，扫描版 PDF 请截图后作为图片发送）、txt / Markdown / CSV / JSON / 各种代码文件；文字上限可在设置里调整。
    - 附件原件保存在 `Mindflow/附件/`，提问上方会显示缩略图 / 文件卡片，点击可在 Obsidian 里打开。
11b. **划线复制**：划线后弹出的小窗里有「复制」按钮（手机上是底部「追问 | 复制」按钮），复制的内容带公式的 LaTeX 源码；直接按 Ctrl+C 也一样会带上公式。
12. **收藏夹**：在 AI 回答（或你的提问）上右键 →「加入收藏夹…」，把这一轮问答放进指定收藏夹；历史里的对话右键也能「加入收藏夹…」（收藏整个对话）。左侧栏「收藏夹」按钮把历史列表切换成收藏夹：
    - 右上角按钮：新建收藏夹、把全部收藏夹生成 Canvas、返回历史；
    - 收藏夹支持多级：右键收藏夹 → 新建子收藏夹 / 加入已有对话 / 生成 Canvas / 重命名 / 移动到 / 删除；
    - 点收藏的问答会打开对应窗口并滚动到那条回答；右键可移动到别的收藏夹或移出；
    - 「生成 Canvas」会在 `Mindflow/总览图/` 生成一张画布：每个收藏夹是一个分组（子收藏夹嵌套在里面），问答是一张带完整回答的卡片，整个对话按问答树展开，卡片标题可以跳回对话。
    收藏夹数据保存在 `Mindflow/收藏夹.json`。
13. **想法笔记**：在回答里划选一段，右键 →「记笔记…」（或划线弹窗里的「笔记」，手机上底部的「笔记」按钮），写下看到这句话时的想法。弹窗里原文和你的想法都会渲染（公式、符号、加粗都正常显示），可以选择或新建文件夹，Ctrl/Cmd+Enter 保存。记过笔记的原文在对话里显示为蓝色虚线下划线，点它可以查看 / 修改笔记。
    - 左侧栏「笔记」进入笔记页面：左边是「全部笔记」「未分类」和多级文件夹（右键：新建子文件夹 / 重命名 / 移动 / 删除，删除文件夹时笔记会移回「未分类」）；右边是笔记卡片，支持搜索。
    - 点笔记卡片会跳回当时划线的对话，并闪烁标出那段原文；卡片上还可以编辑、移动、复制、删除。
    - 笔记保存在 `Mindflow/想法笔记.json`。
14. **设置**：左侧栏「设置」直接打开插件设置，可选服务商预设（DeepSeek、OpenAI、Kimi、通义千问、智谱、硅基流动、OpenRouter、Ollama）、获取模型列表、最大回复长度、发送方式、回答字号、划线追问默认问题、保存位置等。

对话数据保存在 `Mindflow/对话数据/*.json`（可在设置里改文件夹），随库同步。

## 在安卓手机上使用

1. 把插件包解压，得到 `canvas-mindflow` 文件夹（里面有 main.js、manifest.json、styles.css）。
2. 用文件管理器（需要能显示隐藏文件，比如 MT 管理器、Solid Explorer）把整个文件夹放到：
   `你的库/.obsidian/plugins/canvas-mindflow/`
3. 打开 Obsidian → 设置 → 第三方插件 → 关闭「安全模式」→ 点刷新 → 启用 Canvas Mindflow。
4. 在插件设置里选服务商、填好 API Key。

手机上会自动切换成单栏：左上角按钮打开历史/导航抽屉，右上角按钮打开问答树/追问抽屉；长按选字后，底部出现「追问选中内容」按钮，点它后原文会作为「引用」出现在输入框上方，直接在输入框里写问题发送即可（留空发送 = 详细解释这段），点 ✕ 取消。

## Canvas 卡片对话

在 Obsidian Canvas 里和 AI 对话：**一张卡片 = 一个问题 + 它的回答**。回答就写在同一张卡片里，Markdown 原生渲染，可以折叠，卡片可以随意拖大拖小；划选回答里的任何一句话，就能从这句话分支继续追问。

## 快速上手

1. 设置 → Canvas Mindflow → 选服务商、填写 API Key 和模型 →「测试」。
2. 打开或新建一个 `.canvas`，双击空白处新建卡片，写下问题。
3. 按 **Ctrl/Cmd + Enter**：AI 的回答会流式写进这张卡片。
4. 读回答时，**先单击选中卡片**，再在回答区域里拖动鼠标划选文字 → 按 **Tab** 或点「✦ 追问」→ 输入问题，按 Enter（留空就是"详细解释这段"）。
   右侧会长出一张带原文锚点的子卡片，并且马上开始回答。
5. 点回答上方的标题可以折叠或展开：展开时卡片自动放大到能完整显示（上限可设），折叠时恢复到展开前的大小；问题始终固定在卡片顶部，回答在框内滚动。

## 快捷键与菜单

| 操作 | 方式 |
|---|---|
| 回答 / 重新回答 | `Ctrl/Cmd + Enter`（编辑卡片时或选中卡片时都可以）· 右键 →「让 AI 回答」 |
| 新建空白追问卡片 | 选中卡片后按 `Tab` · 右键 →「追问（新建子卡片）」 |
| 划词追问 | 划选文字 → `Tab` 或「✦ 追问」 |
| 折叠 / 展开 | 点「回答」标题 · 右键菜单 · 命令「折叠/展开画布上所有回答」 |
| 汇总多张卡片 | 多选卡片后右键 →「汇总提问」 |
| 停止生成 | 右键 →「停止生成」· 命令「停止所有生成」 |
| 在视口中央新建问题 | 命令「在画布中央新建问题卡片」（可以在快捷键设置里绑定） |

## AI 看到的上下文

- 沿着连线向上的**所有祖先卡片**（父在前、子在后）。每张卡片都会作为"用户问题 + AI 回答"一起发送。
- 离当前卡片 3 层以内的回答发全文，更远的只发前 600 字（可以在设置里调）。
- 连到问题上的**笔记文件卡片**，其内容会作为资料发送；普通的文字卡片（里面没有 AI 回答）作为"背景资料"发送。
- 想让 AI 基于某篇笔记回答：把笔记拖进画布，然后连一条线到问题卡片上。

## 数据格式

卡片就是普通的 Markdown，即使卸载插件也能正常阅读：

```markdown
==划选的那句话== 我的问题

> [!ai]+ 回答
> AI 的回答……
```

`[!ai]+` 表示展开，`[!ai]-` 表示折叠。展开前的卡片尺寸记在 .canvas 的 `cmfPrevSize` 字段里，折叠时据此恢复。

## 数据与隐私

- API Key 只保存在你本地库的插件数据里（`.obsidian/plugins/canvas-mindflow/data.json`），**不要把这个文件提交到公开仓库**。
- 对话请求直接从 Obsidian 发往你配置的 AI 服务商，插件本身不经过任何第三方服务器、不收集数据。
- 对话、笔记、收藏夹、附件都以 JSON / 普通文件保存在库里的 `Mindflow/` 文件夹，随库同步，卸载插件也不会丢。

## 开发

不依赖 npm 包，源码在 `src/`，构建只是把几个文件拼起来：

```bash
sh build.sh        # 生成 main.js
node test/run.js   # 运行测试（用假的 obsidian 模块在 Node 里跑）
```

| 文件 | 内容 |
|---|---|
| `src/core.js` | 设置、AI 请求（流式）、Canvas 卡片对话、公式选区工具 |
| `src/chat.js` | 对话视图：主窗口、追问卡片、问答树、左侧栏 |
| `src/fav.js` | 收藏夹及导出 Canvas |
| `src/notes.js` | 想法笔记 |
| `src/attach.js` | 图片 / 文件附件 |

调试时把仓库目录链接（或复制）到某个测试库的 `.obsidian/plugins/canvas-mindflow/`，改完运行 `sh build.sh`，在 Obsidian 里重新加载插件即可。

发布新版本：修改 `manifest.json` 和 `versions.json` 里的版本号，提交后推送同名 tag（例如 `git tag 0.10.1 && git push --tags`），GitHub Actions 会自动构建并创建 Release。
